# Basic Reporting - Lite Summary

Generate daily attendance and violation reports with filtering, multi-format export (PDF, Excel, CSV), and scheduled email delivery. Supports manager and company-wide views with date range and employee filtering.

## Key Points
- Daily attendance reports showing work hours, breaks, overtime, and status per employee
- Violation summary reports with type, severity, and repeat offender analysis
- Multi-format export (PDF for printing, Excel for analysis, CSV for integration)
- Scheduled automated report delivery via email (daily/weekly)
- Flexible filtering by date range, department, employee, violation type, and severity
