# Daily Attendance Summary Generation - Lite Summary

Automatically generate daily attendance summaries with calculated work hours, break duration, overtime, and status determination. Updates in real-time as events occur and supports historical recalculation, providing a single source of truth for reporting and payroll integration.

## Key Points
- Real-time summary updates as attendance events are processed
- Automatic work hours, break time, and overtime calculation
- Intelligent status determination (present, absent, half-day, on-leave, holiday)
